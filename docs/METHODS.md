# Methods reference

This guide lists every method in the method registry (`backend/sps/registry.json`, version 0.4.1) with its parameters, defaults and limits. It is generated by `tools/make_methods_doc.py`; do not edit it by hand.

Status "Available" means the method passed the automated backend acceptance tests of this version. "Not implemented" methods are listed for completeness and cannot be selected. Methods marked "experimental" passed the same tests but have known limits that are stated with the method.

Every learned step (preprocessing, variable selection, tuning, interval calibration) is fitted inside the training part of each fold. The outer test observations and a locked independent test set never take part in these steps.

## Validation design

Panel tab: **3 Validation**.

The validation design decides which observations test each model. Outer folds estimate prediction performance. Inner folds inside each outer training part select variables and tune settings, so the outer test observations never take part in these choices. Choose the design that matches the prediction purpose set on the same tab. Observations that share a profile, parcel or farm should be kept together with a grouped or spatial design. Repeated folds give more evaluation records, but they do not add independent observations.

| Method | ID | Status | Description |
|---|---|---|---|
| Random k-fold | `random` | Available | Does not separate dependent groups; for such data, choose the grouped method. |
| Repeated random k-fold | `repeated` | Available | Each repeat is evaluated separately; the number of predictions is not the number of independent samples. |
| Grouped k-fold | `group` | Available | Observations linked by profile, parcel and farm relationships are kept together. |
| Spatial block | `spatial_block` | Available | Metric grid blocks are assigned to folds. This is not an unbiased estimate of map accuracy. |
| Buffered spatial | `buffered` | Available | Training groups closer to the test blocks than the buffer distance are removed. |
| User-defined folds | `custom` | Available | ID coverage, group and distance conditions are still checked. |
| k-fold nearest neighbor distance matching (kNNDM) | `knndm` | Available | Distance matching with local CAST 1.0.4. This version supports only unique independent observations, metric coordinates and at most 2000 training points. |
| Environmental clusters | `environmental` | Not implemented | Environmental transfer must be tested separately. |
| Time-ordered validation (new groups) | `temporal` | Available | A date field is required. Profiles and same-day observations are not split. The training history moves forward; calibration is held out from the last eligible periods. Evaluation with fixed rasters does not validate a map for a specific future date. |
| Design-based map validation (probability sample) | `design_based` | Not implemented | A weighted estimator that matches the sampling design is not implemented yet. |

## Target transformation

## Multicollinearity (variance inflation factor)

Panel tab: **5 Variable selection**.

The variance inflation factor (VIF) measures collinearity among continuous covariates. The diagnostic mode only reports it. The iterative mode removes covariates above the threshold inside each training part.

| Method | ID | Status | Description |
|---|---|---|---|
| Off | `off` | Available | Multicollinearity is not diagnosed. |
| Diagnostic only | `diagnostic` | Available | The variance inflation factor (VIF) measures collinearity among covariates. It does not eliminate variables. |
| Iterative elimination | `iterative` | Available | Continuous variables that exceed the threshold are eliminated one at a time within training. Categorical indicator columns are not split up. |

### Off (`off`)

Multicollinearity is not diagnosed.

Cost: Increases with data size and number of folds.

## Prediction intervals

Panel tab: **8 Uncertainty**.

A prediction interval is not a confidence interval. Empirical coverage is tested in the outer evaluation and must be read together with the interval width. Nominal coverage is not an exact guarantee for spatial or grouped data.

| Method | ID | Status | Description |
|---|---|---|---|
| No interval | `none` | Available | Point prediction only. |
| Split conformal | `split_conformal` | Available | Builds intervals from the absolute errors of separate calibration observations. |
| Quantile regression forest | `quantile_forest` | Available | True conditional quantiles in the random forest family. Coverage without calibration is tested in outer folds. |
| Gradient boosting with quantile loss | `quantile_boosting` | Available | Separate lower and upper quantile models in the histogram-based gradient boosting family. |
| Conformalized quantile regression (CQR) | `cqr` | Available | Adjusts the quantile interval with separate calibration data. |
| Group bootstrap spread | `group_bootstrap` | Not implemented | This is modeling variability; it is not a prediction interval for observations. |
| Spatially weighted conformal (experimental) | `spatial_conformal` | Available | Weights separate calibration residuals by distance. There is no exact coverage guarantee. If local support is insufficient, the point prediction is kept; no interval is produced. |
