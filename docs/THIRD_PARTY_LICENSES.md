# Third-party components

Install.cmd downloads the packages below from their public sources (python.org builds on nuget.org, the Python Package Index and download.pytorch.org). Each package keeps its own license. The licenses listed here are the ones each package declares in its own metadata. Read the full license text in the installed package folder before you redistribute anything.

Generated by `tools/make_third_party_doc.py` from the Windows wheels of the pinned versions.

## Runtime and build tools

| Component | Version | Source | License |
|---|---|---|---|
| CPython (private runtime) | 3.12.3 | nuget.org package `python` | Python Software Foundation License (`LICENSE.txt` in the runtime folder) |
| Roslyn C# compiler | 4.14.0 | nuget.org package `Microsoft.Net.Compilers.Toolset` | MIT |
| .NET Framework 4.8 reference assemblies | 1.0.3 | nuget.org package `Microsoft.NETFramework.ReferenceAssemblies.net48` | as stated by the package: https://github.com/Microsoft/dotnet/blob/master/LICENSE |

The compiler and the reference assemblies are used only on your computer to build the add-in; they are not copied into the add-in.

## Model weights

TabPFN v2 regression weights (Prior Labs, revision pinned in `tools/setup-tabpfn-weights.py`) are downloaded only when you run `Install.cmd -WithTabPFN -AcceptTabPFNLicense`. They are licensed under the Prior Labs License 1.1, which the installer saves next to the weights. The `tabpfn` Python package itself is installed in every installation under the same license. Paragraph 10 of that license asks products that contain TabPFN source or weights to display "Built with PriorLabs-TabPFN" in their documentation and user interface. The README, the method description in the panel and the reports display it.
